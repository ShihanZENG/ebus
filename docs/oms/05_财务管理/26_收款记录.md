# 26 收款记录

> **实现状态：部分实现**。订单级付款记录可登记和查询；财务页面展示的是另一来源的 DataLab 每日汇总，不是本地付款明细。

## 业务说明

本主题包含两类数据，使用时应区分：

1. **订单付款记录（OMS 本地）**：人工登记一笔订单付款，记录订单、金额、币种、支付方式、来源、到账时间和备注。记录与订单关联，可在订单详情中查看。它是记账记录，不会自动向 PayPal 或电商平台收款，也不代表已和银行或平台结算单核对。
2. **财务每日汇总（DataLab）**：前端财务页面读取 DataLab `dws_finance_day` 表的汇总行，展示业务日期、类型、状态、币种、笔数和金额，并按 CNY/USD 汇总金额。它不是 OMS 的付款记录表，也没有与订单付款逐笔关联。

## 操作路径

- 订单付款记录：订单详情抽屉可查看已有记录，并在有 `payment_records:write` 权限时通过表单登记新付款；已取消订单不能登记。
- 财务每日汇总：左侧菜单 → 财务 → 结算管理（`/finance-settlements`）。

## 数据来源与接口

- 本地表：`payment_records`，字段包括 `order_id`、`amount`、`currency_id`、`method`、`source`、`paid_at`、`remark`。
- 订单付款接口：`POST /api/v1/orders/{order_id}/payments`、`GET /api/v1/orders/{order_id}/payments`；具有 `payment_records:read` 权限时，订单详情也返回 `payments`。
- DataLab：`GET /api/v1/datalab/table/dws_finance_day?limit=100`。该接口代理查询外部数据仓库表。

## 当前操作细节与边界

### 本地订单付款记录

订单付款接口的请求体字段为 `amount`、`currency_id`，以及可选的 `method`、`source`、`paid_at`、`remark`。金额使用两位小数口径；未传 `paid_at` 时以服务端当前 UTC 时间登记。成功响应包含付款记录 ID、订单 ID、金额、币种 ID、方式、来源、时间、备注及创建/更新时间。查询按 `paid_at`、记录 ID 升序返回 `{items}`，没有独立分页、筛选或修改/删除接口。

调用者需要 `payment_records:write` 才能登记，`payment_records:read` 才能查询；订单还必须在调用者店铺范围内。已取消订单不能登记付款，币种必须是启用的币种字典且与订单币种完全一致。当前没有校验累计收款不能超过订单应收，也没有付款幂等键；重复 POST 会形成两条记录。该接口只记账，不执行扣款、收款、渠道查询或核销。

### 财务结算管理页面

菜单“财务 → 结算管理”对应 `/finance-settlements`，路由要求 `dashboard:read`。页面只在打开时请求一次 `GET /api/v1/datalab/table/dws_finance_day?limit=100`，表格显示返回行的 `business_date`、`type`、`status_text`、`currency`、`entry_count`、`amount`；“财务记录数”和 CNY/USD 卡片均由当前返回的最多 100 行在浏览器端求和。没有期间筛选、翻页、导出、刷新控件或数据更新时间展示；页面加载失败只提示“财务数据加载失败”。

DataLab 通用查询 API 将 `limit` 限制在 100 以内，缺省为 50；它代理外部表数据，不在 OMS 保存查询快照。返回行数受限，未知币种不进入 CNY/USD 两个合计，且页面未进行跨币种换算。故页面金额不是全量结算额，也不能视作订单付款逐笔明细。外部服务超时、表不可用或字段结构变化都会导致加载错误或显示不完整。

## 建议验收

1. 为测试店铺创建一笔未取消订单，以相同币种登记金额 `12.34`、方式 `manual`、来源 `manual`，确认返回并在付款查询/订单详情看到一条付款记录，金额为 `12.34`。
2. 对取消订单登记付款，预期 422；传入与订单不同或已停用的币种，预期 422；无 `payment_records:write` 权限预期 403；不在店铺范围内预期不可见（404）。重复提交相同请求会新增第二条，验收时应确认当前无去重保证。
3. 检查财务页面只展示至多 100 条 DataLab 返回行；准备超过 100 行的数据时，页面合计只应基于本次返回行。检查该页面未展示支付明细、渠道流水或全量期间总额。
