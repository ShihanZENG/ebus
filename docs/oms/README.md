# OMS 订单管理系统 - 文档目录

> **阅读说明：**35 篇章节已按当前代码细化，覆盖业务场景、操作或目标流程、关键字段与状态、权限与数据范围、异常边界及建议验收。章节中的“文档已细化”只说明文档工作完成，不表示对应页面、接口或业务闭环已经实现；功能状态以各篇“已实现／部分实现／尚未实现”为准。

> 技术栈：React 18 + TypeScript + AntD 5（前端）/ FastAPI + PostgreSQL（后端）
> 参考风格：领星ERP（深色窄侧边栏 + 顶部标签栏）

开发环境中 OMS 与 ERP 共用 `http://127.0.0.1:15173` 这一前端入口，OMS 页面位于“销售”导航；`/api` 统一代理到后端 `18080`。角色和数据范围由现有权限系统控制。

先读 [状态与接口速查](./状态与接口速查.md)；需要继续扩写或验收时参照 [编写与验收规范](./编写与验收规范.md)。

后端开发进展及验证结果见 [订单编辑交付说明](./后端订单编辑交付说明.md)。

## 当前能力速览

| 领域 | 当前系统状态 |
|---|---|
| 订单 | 手工创建、CSV/TSV 手动导入页面、列表筛选分页/详情、逐单审核、申请发货、取消、履约前编辑抽屉；平台自动拉单、拆合单与批量状态处理尚未实现 |
| 售后与客服 | 订单退货/退款申请登记、售后列表分页和基础状态处理、内部客服工单；实际退款执行、退货入库、换货和平台消息尚未实现 |
| 渠道与客户 | 店铺档案及本地 Listing 映射；平台授权和同步日志未实现，独立客户主档、客户标签未实现 |
| 财务 | 订单详情登记/查看付款、DataLab 财务日汇总只读展示；退款支付、利润核算和逐笔对账未实现 |
| 设置 | 仓库档案、账号角色和审计日志；物流渠道配置、运费模板、通用打印模板未实现 |
