# 07 订单详情

## 文档状态

详情抽屉只展示有限的订单字段和商品、付款记录；数据库没有收件地址字段，也没有订单操作时间线展示。

## 当前展示

订单抽屉显示来源单号、来源渠道、状态、客户名称、客户联系方式、应付金额、商品 SKU 快照/数量/行金额；具有 `payment_records:read` 的账号可查看付款记录，具有 `payment_records:write` 的账号可在抽屉登记付款。

## API 返回

`GET /api/v1/orders/{order_id}` 返回订单字段及商品明细；仅对具有对应读取权限的账号附带 `payments`、`after_sales`。前端当前没有呈现售后记录。订单模型没有渠道下单/付款时间、收件人地址、物流渠道、运单号等字段；WMS 出库单另存运单号及发货时间。

## 状态

- **已实现**：订单详情接口、商品明细和付款记录显示。
- **部分实现**：API 有售后记录，但此抽屉未显示；审计日志有订单操作记录，但没有详情时间线。
- **未实现**：收货地址、物流轨迹、签收时间、订单打印。

## 代码位置

- 前端详情抽屉：`frontend/src/pages/Orders.tsx`
- API：`backend/app/orders.py` 的 `order_detail`
- 订单与明细模型：`backend/app/models.py` 的 `SalesOrder`、`SalesOrderItem`
- WMS 运单和发货字段：`backend/app/models.py` 的 `ShipmentOrder`

## 字段口径与查看步骤

在订单列表单击某行，前端按内部订单 ID 请求 `GET /api/v1/orders/{order_id}` 并打开抽屉。可供核对的核心字段包括来源渠道/来源单号、订单状态、客户名称/联系方式、币种与应付金额；商品明细使用创建时保存的 SKU 编码和名称快照，数量、单价、优惠、行金额来自订单行。金额单位为订单币种，行金额已扣本行优惠。

API 对有权限账号还返回付款记录和售后记录。付款条目含金额、币种、方式、来源、时间和备注等；售后条目含类型、原因、状态、数量和金额。当前抽屉可查看付款金额、方式、来源、时间和备注并登记新付款；不渲染售后列表，也没有显示审计日志。客户联系方式是自由文本，并非经验证的手机号；系统没有收件人地址字段。

### 范围与边界

详情查询需要 `orders:read`，并校验订单所属店铺范围。看不到或超出范围时服务端返回 404；付款和售后数据分别要求 `payment_records:read`、`after_sales:read`，权限不足时响应省略对应字段。WMS 的运单号、发货时间保存在出库单，不由这个详情响应自动拼装展示。

建议验收：打开包含多行商品和两笔付款的订单，核对 SKU 快照、金额及付款项；创建一笔售后后确认详情 API 有 `after_sales`，同时当前抽屉不会呈现该段；再验证范围外订单无法通过替换 ID 读取。未来若增加时间线，需区分订单审计事件、付款、售后和 WMS 出库事件来源。建议步骤未执行。
