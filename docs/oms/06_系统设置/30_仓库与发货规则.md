# 30 仓库与发货规则

> **实现状态：部分实现**。仓库档案 CRUD 和订单履约仓库指定已实现；按国家、SKU 自动选择仓库等发货规则未实现。

## 业务说明

仓库档案维护仓库编码、名称、类型、国家、地址及启停状态。订单审核/申请发货时可指定履约仓库；申请发货会按订单明细预留该仓库存量，仓库确认出库后扣减库存。系统当前不会根据国家、SKU 或优先级自动选择仓库。

## 仓库字段

| 字段 | 说明 |
|------|------|
| 仓库编码、名称 | 档案识别信息 |
| 类型 | 国内仓或海外仓 |
| 国家、地址 | 仓库所在地信息 |
| 状态 | 启用/停用 |

库位、联系人、FBA 仓类型等不属于当前仓库档案字段。

## 操作路径

左侧菜单 → 资料管理/系统设置 → 仓库档案；订单审核或申请发货时指定履约仓库。

## 数据来源与接口

- 本地表：`warehouses`。
- 通用资料接口：`GET /api/v1/warehouses`、`POST /api/v1/warehouses`、`PATCH /api/v1/warehouses/{id}`。
- 订单发货流程：订单审核指定仓库，发货申请调用 WMS 预留库存。

## 页面/API操作与范围限制

仓库页路由为 `/warehouses`，通用资料接口为 `GET/POST /api/v1/warehouses`、`GET/PATCH /api/v1/warehouses/{id}`。列表支持 `q`、`is_active`、`page`、`page_size`（最大 100）；字段由创建模型约束：`code` 唯一、名称、类型 `domestic|overseas`、非空国家、最长 500 字地址和启停状态。编码创建后不可修改。读取要求 `warehouses:read`；写入要求 `warehouses:write`。有限仓库范围用户只能读取/更新授权仓库，且不能新建仓库；新建需要全范围权限。

页面通过通用 `ResourcePage` 提供档案维护。订单审核接口 `POST /api/v1/orders/{id}/approve` 和发货申请接口要求 `orders:write`，同时校验订单店铺范围、仓库启用状态和操作者的 `warehouse_scope`。全范围 (`None`) 可选择任意启用仓库；有限范围只能选择授权仓库，空范围不能操作仓库。范围外请求在更新订单、预留库存和写审计前返回 403。

WMS 申请发货时要求订单已审核、有明细、仓库有效、可用量足够且订单没有既有出库单；失败库存不足返回 422，重复申请返回 409。它会生成出库单并增加预留量，不在此时扣减在库。确认出库后才扣减在库和预留量。系统没有默认仓、国家或 SKU 路由规则，审核/申请时仓库需人工指定。

## 建议验收

1. 全范围用户创建国内仓，读取、编辑地址、停用仓库均成功；重复编码应失败。停用仓不能作为订单履约仓库。
2. 仓库范围用户只看到授权仓；尝试读取或更新范围外仓库不可访问，尝试新建返回 403。
3. 对有库存订单申请发货后，库存流水出现 reserve、可用库存减少而在库不变；确认出库后才出现 outbound 且在库减少。可用库存不足应返回 422，重复申请应返回 409。
4. 用仅授权仓库 A 的账号尝试审核到仓库 B、改选仓库 B 申请发货；预期 403，订单状态、库存预留及审计记录不变。步骤待执行。
