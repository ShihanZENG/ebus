# 33 打印模板

> **实现状态：未实现（通用打印模板）**。系统有 FBA 标签清单页面，但打印按钮仍提示“打印功能开发中”，不能视为模板编辑或实际打印已完成。

## 业务说明

规划为拣货单、发货单、面单及装箱单提供可配置打印模板。现有 FBA 标签页面读取 DataLab 的商品/FBA 维度数据并列出卖家 SKU、FNSKU 等信息；单条和批量打印操作均为占位提示，没有生成打印文件、打印预览或模板管理能力。

## 规划单据类型

| 单据 | 用途 |
|------|------|
| 拣货单 | 仓库按单拣货 |
| 发货单 | 包裹内商品清单 |
| 面单 | 承运商运输标签 |
| 装箱单 | 包裹/箱内明细 |
| FBA 标签 | FBA 商品标签清单及标签输出 |

## 操作路径

系统设置 → 打印模板（当前无对应设置页面）；FBA 标签清单位于 FBA 标签打印页面。

## 建议目标流程与实现范围

建议用户从具体业务单据（拣货单、出库单、装箱单或 FBA 标签）发起打印：系统按单据类型和仓库/店铺选择已发布模板，生成预览文件，再由用户下载或调用浏览器打印。模板需有草稿、发布版本、停用状态；渲染只允许读取该单据授权范围内的数据，模板变量须经白名单校验，避免任意表达式执行或读取不相关字段。已生成文件应记录模板版本、单据 ID、生成时间和操作者，以便复核。

建议新增打印模板及版本对象，字段包括模板名称、单据类型、页面规格/方向、字段与布局配置、条码/二维码配置、版本号、状态和适用范围；新增模板 CRUD/预览/发布、单据打印数据预览、PDF 生成/下载接口。页面建议提供模板管理器以及各单据详情的打印预览/下载入口。FBA 标签当前来源是 DataLab `dwd_listing_fba_dimensions`，请求最多 100 行，数据行不是 OMS 发货单；在建立数据完整性和标签版式规则前，不应将该清单直接打印当作履约标签。

## 建议验收

1. 对含多 SKU、中文、长名称和条码字段的样例单据生成 PDF，页边距、分页、字体和条码可读；预览与下载内容一致。
2. 发布新模板版本后新打印使用该版本，历史打印记录保留实际模板版本；未发布模板不能供普通用户打印。
3. 使用者只能打印其店铺/仓库范围内的单据，模板变量越权访问被拒绝；打印日志包含操作者、单据、模板版本和时间。
4. 空数据、超长明细及文件生成失败需给出明确提示；批量打印部分失败时返回逐单结果，不丢失成功文件引用。
