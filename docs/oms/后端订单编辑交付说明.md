# OMS 后端订单编辑交付说明

日期：2026-10-09。当前按后端优先推进，本批未修改前端。

## 接口

新增 `PATCH /api/v1/orders/{id}`，支持客户名称、联系方式、备注、履约仓和商品明细编辑。原因必填，金额由服务端重算，详情规则见 [订单编辑文档](./01_订单中心/10_改地址改商品改数量.md)。

草稿可编辑，已审核订单编辑后退回草稿。已有出库单或已进入履约/取消阶段时禁止编辑。新应付金额不得低于累计付款。编辑需要订单写权限及对应店铺、仓库范围；审计保存变更原因与前后商品快照。

接口使用现有数据表，无新增数据库迁移。部署时重启后端加载新路由即可；前端编辑入口留待后续接入。
