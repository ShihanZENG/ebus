# 企业经营管理端 G0 功能状态台账

盘点日期：2026-10-21。对照《CommerceOS 企业经营管理端详细需求文档（PRD）v1.0》及当前源码。此表记录代码能力、系统连接、PRD 验收和生产验证四种不同状态；“已有实现”不代表满足新 PRD，也不代表生产可用。

## 状态口径

- **实现**：已实现 = 源码中存在可调用的业务能力；部分 = 仅覆盖部分目标、缺少流程或关键边界；未实现 = 未发现对应能力。页面或模型定义本身不算端到端实现。
- **联通**：ERP 本地 = 前端/API 接入本地 ERP 数据库；OMS 独立 = 仅在 OMS 自己的服务和数据库内联通；DataLab = 从配置的数据源查询，部署真实性和刷新需另核；Mock = 仅模拟适配；人工输入 = 依靠人工提供结构化数据；未接入 = 无可用系统接口。
- **验收**：本轮没有按 PRD 的 Given/When/Then 对 55 项能力逐项执行验收；已有测试文件或历史交付说明只能作为测试资产，不能替代本轮结果。
- **生产**：没有本轮生产环境验收证据。凡未明确验证真实服务、权限、覆盖范围、故障恢复和监控者，均标为“未验收”。

来源说明：功能和代码边界参照[现有功能清单](./现有功能清单-需求对齐用-2026-10-20.md)、[ERP 后端接口说明](../backend/README.md)、[独立 OMS 说明](../oms/README.md)及下表列出的源码。PRD 目标编号对应本次附带的 BIZ-FR-001–024。未在代码或交付文档中找到证据的部分保持未验证，不按页面名称推断。
