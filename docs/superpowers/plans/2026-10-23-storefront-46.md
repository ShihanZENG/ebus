# Storefront 4.6.3–4.6.8 页面与功能补齐

**Goal:** 对照用户提供的 4.6.3–4.6.8（Storefront 页面清单、商品展示与购买、购物车与 Checkout、消费者账户与订单、跨系统依赖、优先交付范围），在既有织间商城上补齐缺口，不重复实现已有页面。

**Architecture:** Vite + React 商城前端与 FastAPI 演示工厂后端；订单仍由 ERP 销售订单承载，Storefront 通过授权接口展示。支付为沙盒测试流程，不接真实网关。

## 现状核对（已存在，不重复实现）
- P0：首页、商品列表/详情、购物车、结账（地址+订单创建）、基础账户与游客结账、订单创建与查询均已有。
- P1：搜索与筛选、FAQ（帮助页）、内容页面（关于/政策）已有基础。

## 本轮缺口与实现
1. **支付测试流程（STO-PG-007，P0）**：新增 `storefront_payments` 表与测试支付接口；沙盒支付成功/失败两种情景由服务端模拟并记录 provider_ref，失败可重试（同情景幂等）。订单视图返回支付状态与金额。
2. **结账优惠（STO-PG-006，P0）**：新增 `storefront_promos` 表；Checkout 接受优惠码，服务端校验并计算折扣（百分比/固定、最低金额、上限、次数），订单金额仍由服务端重算；OrderMeta 记录优惠码与折扣。
3. **商品详情配送说明（4.6.4，P0）**：详情弹窗新增“配送说明”折叠区，数据来自站点配置（币种、运费、配送区域）。
4. **个人中心（STO-PG-009，P1）**：顾客资料（显示名、电话、尺码偏好）、收货地址簿（增删改查+默认地址），结账支持从地址簿选择/保存地址。
5. **售后申请（STO-PG-012，P1）**：新增 `storefront_after_sales` 表；按订单商品行申请退货/退款（数量不超过购买数），顾客查询状态；运营端（独立站运营页）处理状态与备注。
6. **内容页面（STO-PG-015，P1）**：拆分配送政策、退货政策、隐私说明独立路径。
7. **活动与专题页（STO-PG-014，P2 轻量）**：前端配置驱动的专题页 `/campaigns/*`，基于分类聚合商品陈列。

## Global Constraints
- 保留既有未提交工作；新增表/列/接口，不改写已有下单幂等、访问凭据与越权保护。
- 支付为沙盒：不接真实扣款；支付结果由服务端生成，客户端不可伪造。
- 售后/地址/资料均做服务端归属校验（订单凭据或顾客会话），不能越权读取他人数据。
- 金额计算全部服务端完成；优惠码幂等（重放不重复占用次数）。

## Review Focus
- 越权（他人订单/地址/售后）、重放与重复占用优惠码、售后数量超购、支付失败恢复、金额与折扣一致性。
