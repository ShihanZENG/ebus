## 业务口径

同一个仓库、SKU 的在库数分为公共与各店铺专属。公共数等于在库总数减专属总数。未占用数等于在库减所有任务占用。订单和调拨审批优先使用本店专属未占用数，再使用公共未占用数；不能取其他店铺专属库存。专属数量调整须保留说明和审计，不能转走已占用数量，也不能把库存总数调高。

买家订单申请发货时占用，取消申请释放，确认出库同时减少在库和占用。仓间发货计划提交后待审批，审批时占用，取消释放，确认发货同时减少在库和占用；目的仓签收增加在库。进入 FBA 的货归目标店铺专属；国内发海外仓时，专属部分沿用原归属，公共部分仍为公共。

发货计划支持国内仓直发 FBA、国内仓发海外仓、海外仓补 FBA 三条路线。海外仓买家订单沿用既有订单出库流程。页面位于「仓储物流 → 库存 → 库存归属与需求」和「FBA 发货计划」。

## 需求传递

`GET /api/v1/inventory/demand-summary` 逐仓显示现有买家订单、已提交或已审核调拨、已占用数量、尚可试分配数量、现货缺口和独立列出的待到货单据。试分配只用于查看，不锁库存。

`GET /api/v1/inventory/route-demand` 把海外仓现有单据缺口向指定国内仓传递。它按店铺扣除已提交、审核或在途的国内发海外仓任务，再试用国内仓剩余现货；已有任务造成的国内仓缺口只算一次。需要完整店铺和仓库数据范围才能查看跨店铺汇总。

路线结果仅表示当前已存在单据的现货缺口。它尚未计算未来销量、促销、新品预测、运输能否赶上需求、采购在途是否可及时使用，也不应直接作为采购单数量。多店铺预测采购在原 Agent 中仍会阻断并提示汇总核对。

## 现阶段业务边界

- 发货计划签收仍为整单全量，尚无部分签收、损耗、质检和上架待可售阶段。
- 仓库基础资料只有国内或海外分类；FBA 与普通海外仓在界面按路线区分，尚需为真实仓库维护仓库用途，避免误选目的仓。
- 既有库存余额没有货主、标签、批次和质检状态依据；迁移不猜测归属，全部保留公共口径。业务人员核实后可逐项设为店铺专属。
- 当前 Agent 仍按单配置计算 7/21 天日销；多店铺未来需求尚未合并为统一采购建议。跨仓当前单据缺口与未来需求必须在采购规划中进一步合并，并按可用日期扣减。
- 已签收进入目的仓时目前即计入在库；平台签收、质检、上架可售若有时间差，应继续细化状态和库存口径。
