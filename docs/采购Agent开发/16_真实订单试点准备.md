## 将来拿到资料时的最小路径

1. 从实际销售平台导出连续 21 天订单，保留平台订单号、平台 SKU、实际下单时间（含时区）、件数和订单状态；导出范围应包括零订单日期。
2. 对照本地 SKU 编码或维护平台 SKU 映射，先导入一小段并核对订单号去重、业务日期和件数，再导入完整区间。
3. 核对订单状态与仓库归属，确认哪些订单属于海外仓一件代发、哪些销售需求去 FBA；取得库存和运输 ETA 后再运行按日供需。
4. 对来源报表保存文件名、导出范围、导出时间及负责人；不要用系统创建时间补造历史业务下单时间。
