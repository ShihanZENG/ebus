# 05 前端页面

> 本文为首次页面设计，独立子路由属于原设计而非实际交付。当前实现为 /purchase-agent 内的ERP供需规划和手工参数测算，供需规划包含工作台、业务配置、草稿、运行记录四个标签。详见 [08_上线能力与补充数据](./08_上线能力与补充数据.md)。

- 文档编号：AI-SCM-05
- 上游：`02_架构与数据模型.md`
- 状态：定稿（页面为可选增强，后端闭环为验收主线）

## 1. 页面清单

| 页面 | 路由 | 功能 |
|---|---|---|
| 采购 Agent 工作台 | /purchase-agent | 输入 SKU/店铺/仓库/业务时点/日销等参数 → 发起 decide → 展示证据、计算过程、结果状态；BLOCKED 显示缺失项；生成草稿后跳转草稿列表 |
| 采购草稿列表 | /purchase-agent/drafts | 草稿状态、幂等键、快照、审批按钮；支持按状态筛选 |
| 草稿审批详情 | /purchase-agent/drafts/:id | 证据与中间值展示、批准/驳回（驳回需原因）、审批后显示生成的采购计划 |
| 运行记录 | /purchase-agent/runs | 工具调用链、输入输出、快照、耗时 |

## 2. 工作台交互

- 表单字段：SKU（下拉，来自 /api/v1/skus）、仓库（/api/v1/warehouses）、店铺（可选）、业务时点（默认当前时间）、日销量（可选）、交期/安全天数（可选）、预算上限（可选）。
- 提交 → POST /api/v1/purchase-agent/decide。
- 结果渲染：状态徽标（DRAFTED 绿色 / BLOCKED 红色 / CONSTRAINT_CONFLICT 橙色 / CALCULATED 蓝色）；证据与计算卡片；BLOCKED 时展示 blocked_reason 与缺失项。
- 草稿生成后显示"查看草稿"按钮。

## 3. 菜单与权限

- 左侧菜单新增"采购 Agent"分组（入口仅在账号具备 purchase_agent:read 时显示）。
- 前端仅隐藏入口，后端强制校验（不能只依靠页面隐藏按钮）。

## 4. 接口对接

- 页面只调用本文档 03 的 `/api/v1/purchase-agent/*` 接口。
- 错误统一展示 error.message。
