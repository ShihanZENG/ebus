# SKU数据准备清单与自动带入

采购Agent新增「数据准备」页签：选择SKU、配置和统计截止日，查看缺项，点击入口进入订单、供货资料、报价、库存或配置页面。多条配置必须选择店铺和路线，不能用一个SKU的检查替代所有配置。

已经有配置时复用供需分析的证据检查：包括连续21天范围、缺实际下单时间、报价有效期与当前供货价一致性、合规、共享仓库存分配和在途ETA。检查通过只表示证据检查通过，金额和预算仍由规则分析确定。

新增配置选择SKU后自动带入：唯一启用的供应商商品关系、有效订单唯一关联店铺、店铺币种，以及SKU属性中已维护的MOQ、箱规、安全天数、复核周期、运输和入库天数。来源说明展示在表单上。多供应商、多店铺不自动选择；金额币种仍须核对；用户已手填的值不覆盖，已有配置参数不自动改写。

不自动确认合规、完整销量时间范围，不把当前供货价当作已接受报价。供应商交期显示在准备清单中，正式计算仍从已接受有效报价读取。

只读接口：GET `/api/v1/purchase-agent/sku-readiness/{sku_id}`，参数 `business_date`，可选 `profile_id`、`shop_id`。沿用采购Agent读取权限；配置检查验证店铺/仓库范围，订单信息按可见店铺统计。此功能无数据库迁移。
