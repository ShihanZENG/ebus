# 财务：对账结算

## 当前可用的只读页面

“财务 → 结算管理” `/finance-settlements` 已接入 [`FinanceSettlementsPage.tsx`](../../../frontend/src/pages/FinanceSettlementsPage.tsx)。页面从 `GET /api/v1/datalab/table/dws_finance_day?limit=365` 读取最多 365 行 DataLab 财务日汇总，展示日期、类型、状态、币种、笔数和金额，并分别累加返回行中的 CNY 与 USD 金额。它没有本地结算单编辑、差异处理或付款执行能力。

后端销售订单另有付款记录接口和 `PaymentRecord` 模型，采购单保存采购金额，见 [`orders.py`](../../../backend/app/orders.py)、[`models.py`](../../../backend/app/models.py)。这些记录与 DataLab 日汇总尚未构成逐笔可追溯的对账链。页面里的“总额”只是本次取回行的代数和，不能称为净利润或账户余额；不同币种分别显示，不做汇率换算。

## 权限与边界

菜单使用 `dashboard:read`，DataLab 代理接口也要求此权限。前端路由当前只检查登录，直接访问 URL 时没有额外 `PermissionGuard`；接口会在后端拒绝无权限请求。ERP 店铺/仓库数据范围未传给 DataLab 查询。

- **已实现：** DataLab 日汇总只读页面、按币种汇总本次返回行、订单付款记录。
- **部分实现：** 仅取最多 365 行，没有日期/店铺筛选、刷新时间、币种口径与完整性提示。
- **尚未实现：** 平台结算单导入、银行流水匹配、差异处理、应收应付、费用分摊、利润核算、发票及对账审批。

人工验收应对照接口响应检查行数和 CNY/USD 汇总，再选择含退款与平台费用的样例确认金额符号；不要把该页面结果当作已对账金额。本文编写时未执行该操作。
