# 物流：货物运输

## 当前入口

本系统暂没有独立的物流模块。销售履约通过“仓库物流 → 出库单”查看，FBA 头程通过“FBA → 发货流程 → FBA 发货计划”查看。销售出库确认时可登记追踪号，FBA 标记发货时要求填写追踪号。相关字段和动作见 [`ShipmentOrder`](../../../backend/app/models.py) 与 [`wms.py`](../../../backend/app/wms.py)、[`fba.py`](../../../backend/app/fba.py)。

## 已实现的记录

| 场景 | 现有记录 | 不能据此推断 |
|---|---|---|
| 销售订单发货 | 出库单状态、发货时间、追踪号、库存流水 | 承运商已揽收、运输节点或客户签收 |
| FBA 发货 | 计划状态、追踪号、国内仓扣减、海外仓本地签收记账 | Amazon 货件状态或平台实际入仓数量 |
| 采购到货 | 采购收货记录与目标仓库存增加 | 供应商运输轨迹、运费与异常签收 |

## 建议操作与权限

销售发货前先在订单中申请出库，确认实物交运后在出库单填写追踪号并确认发货；这会扣减本地库存。FBA 计划须先审批，标记发货时检查国内仓可用量，实际到仓后再确认本地全量收货。出库需要 `shipments:write`，FBA 状态操作需要 `fba_plans:write`；查看仍需相应读取权限及数据范围。

**已实现：** 本地出库/FBA 计划状态与追踪号记录。**部分实现：** 追踪号只是人工录入字段，没有轨迹校验。**尚未实现：** 承运商与货代主数据、物流轨迹 API、面单/箱贴、运费对账、异常签收、FBA 分箱与短少处理。

人工验收可创建一笔销售订单并走到出库确认，检查追踪号、出库时间、订单状态和库存流水；再重复确认一次，检查系统阻止重复扣库。本文编写时未执行该操作。
