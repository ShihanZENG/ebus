# 15：工具与辅助功能

## 页面用途

当前“工具”分组只有“币种与单位”，路由为 `/dictionaries`，由 [`DictionariesPage`](../../../frontend/src/pages/DictionariesPage.tsx) 提供两页签：币种与单位。它维护订单/付款金额单位、商品计量单位等基础字典，供商品、店铺及订单表单引用；它不是汇率工具、换算器或批量导入工具。

## 操作流程

1. 从“工具 → 币种与单位”进入，切换“币种”或“单位”页签。
2. 通用资源页默认按 20 条分页，支持关键字搜索、启用状态筛选和刷新。
3. 通过“新增”录入编码、名称、状态；编辑时可以修改名称与启用状态，编码和类别不可修改。
4. 停用已有字典后，历史记录仍保留；新商品或订单引用需要有效的启用字典。币种/单位不能在同页相互切换类型。

## 接口和数据

两个页签都调用 `GET /api/v1/dictionaries`，分别附加 `kind=currency` 或 `kind=unit`、分页和可选搜索/状态条件。新增调用 `POST /api/v1/dictionaries`，修改调用 `PATCH /api/v1/dictionaries/{id}`。后端 [`resources.py`](../../../backend/app/resources.py) 限定 `kind` 只能是 `unit` 或 `currency`，按 `(kind, code)` 唯一，写操作记录审计日志；模型定义见 [`models.py`](../../../backend/app/models.py)。引用校验由产品、店铺、订单等相应接口负责。

## 权限说明

菜单及路由要求 `dictionaries:read`；后端列表/详情也要求该读取权限。创建和修改分别需要 `dictionaries:write`。管理员可以访问全部权限页面；其他角色需在“账号与角色”中配置相应权限。读取失败时动态选择项可能无法加载，具体表单会显示错误或空选项。

## 实现状态与缺口

### 已实现

- 币种和计量单位两类字典的分页、搜索、状态过滤、新建和编辑。
- 编码与类别不可编辑；后端限制类别、唯一编码并记录变更审计。
- 停用开关和基础资料引用校验。

### 部分实现

- 页面对两类字典共用通用资源组件，支持分页到每页最多 100 条；字段范围仅编码、名称、状态。
- 停用阻止新引用不代表已有业务记录自动转换；历史金额仍按记录保存的币种 ID 展示。

### 尚未实现

- 汇率维护、币种换算、单位换算及历史汇率生效区间。
- 字典批量导入导出、删除、合并、引用关系检查和变更影响预览。
- 国家/站点、物流方式、税率等更广义配置工具。
