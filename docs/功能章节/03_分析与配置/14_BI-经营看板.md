# 14：BI 经营看板

## 页面用途

“BI → 经营看板”路由为 `/datalab`，由 [`Dashboard`](../../../frontend/src/pages/Dashboard.tsx) 展示来自独立 DataLab 数据仓库的预置数据集。它有销售日报、库存健康、待采购、补货审核和数据质量五个页签，以及近 30 天订单数、净销售额、退款金额和待处理采购单卡片。这里不是 ERP 本地数据库的实时聚合报表；数据刷新时间、ETL 延迟和数据集业务口径需以 DataLab 服务为准。

## 页面使用流程

1. 登录并由有 `dashboard:read` 权限的账号打开“BI → 经营看板”。
2. 页面加载期间显示转圈；成功后查看顶部汇总卡片和五个页签表格。
3. 表格前端每页显示 15 行（部分表无分页）。页面没有日期/店铺筛选和主动刷新按钮，打开时只请求一次。
4. 任一请求整体失败会显示“数据加载失败”；若代理对单个数据集返回 `{error: ...}`，现有页面仍可能把对应数据当空表展示，没有逐表错误提示。

## 数据流与接口

浏览器调用 `GET /api/v1/datalab/overview`，通过统一 Axios 客户端附带登录令牌。后端 [`datalab.py`](../../../backend/app/datalab.py) 代理到独立 DataLab 服务，调用五张固定仓库表，限制分别为销售 30 行、库存健康 50 行、待采购 50 行、补货审核 50 行、数据质量 20 行；上游每张表返回的 `rows` 是前端展示和卡片汇总来源。净销售额和退款卡片分别直接累加返回行的 `net_receipts`、`refund_amount`，均标为 USD；订单总数累加返回行的 `order_count`，待处理采购单数量则只是返回的采购行数。销售金额卡片与销售表的 `order_amount` 不是同一字段口径。

另外还有 `GET /api/v1/datalab/tables`（列出上游表）、`GET /api/v1/datalab/table/{name}?limit=...`（任意表名、默认 50、上限 500）及 `POST /api/v1/datalab/knowledge/search`（知识检索）。当前看板 UI 只调用 overview；其他 API 未在该页面提供交互。当前后端源码包含上游连接地址和访问凭据，应迁移到安全配置并更换已暴露的凭据；本文不记录其值。

## 权限与数据范围

前端菜单权限映射为 `dashboard:read`，BI 路由本身没有单独 `PermissionGuard`；但所有页面仍在登录保护下。后端 overview、tables、table 和 knowledge/search 均由 `require("dashboard:read")` 验证，所以无权限用户 API 请求会被拒绝。代理请求上游时没有把用户的店铺或仓库范围转换成过滤参数；因此该看板的数据隔离不等同 ERP 订单、库存等模块的范围控制。授予此权限前应核实数据仓库自身的租户/行级权限配置。

## 实现边界

### 已实现

- BI 独立导航入口、五个数据集展示和汇总卡片。
- ERP 后端代理上游 DataLab，代理路由检查 `dashboard:read`。

### 部分实现

- 表和行数固定，卡片只对本次返回行求和，不能当作完整全量统计；没有查询筛选和自动刷新。
- 上游失败处理到单表错误对象，但前端未将其显式呈现；总请求失败时仅有通用错误提示。
- 多个表格标注金额为 USD，待采购金额却展示人民币符号，需确认上游币种字段/口径；前端没有通用币种元数据。
- `/table/{name}` 允许调用者指定任意上游表名，目前仅依赖 `dashboard:read` 权限。
- 仓库服务地址/凭据和 TLS 校验配置属于运行配置风险点；应由部署配置管理并核查连接安全。

### 尚未实现

- 页面上的日期、店铺、站点、币种、仓库筛选和查询参数传递。
- 分页、导出、明细钻取、图表、更新时间与数据新鲜度提示。
- ERP 用户数据范围与 DataLab 行级权限联动，以及各指标口径说明。
- 页面调用表目录或知识检索接口的能力。

## 人工验收

文档编写时未执行。使用具备 `dashboard:read` 的账号打开 `/datalab`，确认五个页签能显示且行数不超过接口设定上限；对照浏览器网络响应检查卡片是否按返回行求和，并确认金额字段口径。再用无该权限账号访问页面并直接请求 `GET /api/v1/datalab/overview`，确认后端拒绝。对部分上游表制造不可用情形时，检查其是否被页面误呈现为空表；生产使用前由管理员核实上游数据范围、表权限及数据更新时间。
