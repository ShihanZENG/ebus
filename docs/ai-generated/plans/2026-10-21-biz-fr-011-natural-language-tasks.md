# BIZ-FR-011 自然语言经营任务

## 目标

在现有只读 AI 助手旁提供可追踪的异步任务入口。任务提交前校验目标店铺、SKU 和时间范围；执行过程复用 LIM Run 状态与审计轨迹；用户可查看进度、取消任务并看到失败原因。

## 范围与边界

- 复用 `LimRun` 持久化，不新增数据表或迁移。
- 使用现有只读助手查询能力，不执行审批、采购、库存或外部平台写操作。
- 任务范围只能收窄当前账号的权限范围；显式越权店铺按不可访问处理。
- 当前任务按单轮自然语言查询执行；跨 Agent 编排留给 FR-012。
- 运行任务置于当前应用进程的后台线程；进程重启后不承诺自动恢复。

## 实现文件

- `backend/app/assistant.py`：提取可复用的只读问答函数。
- `backend/app/assistant_tasks.py`：任务请求校验、创建/查询/取消接口和后台执行器。
- `backend/app/bootstrap.py`：登记有固定版本的内置只读助手，满足 LIM Run 的 Agent 外键约束。
- `backend/app/main.py`：注册任务路由。
- `backend/tests/test_assistant_tasks.py`：覆盖有效创建、范围校验、状态读取、取消和失败记录。
- `frontend/src/pages/AssistantTasksPanel.tsx`、`AssistantPage.tsx`：任务提交表单和任务列表/状态/取消交互。
- `docs/AI总助手与多Agent目标架构.md`：记录现有任务接口与运行边界。

## 实施步骤

1. 先写 API 测试，验证授权范围、SKU/日期校验、任务状态和取消；确认缺少接口或行为时失败。
2. 实现后端任务路由和后台执行。运行中取消后，迟到的模型结果不得覆盖 `CANCELLED` 状态。
3. 增加助手页面任务表单和可刷新状态列表，显示 Run ID、状态、来源及失败信息。
4. 运行新测试、相关 LIM/assistant 测试、前端类型检查与构建；最后在共享代码固定后执行全量后端回归。

## 复核重点

- 不接受客户端传入 tenant、actor 或扩大权限的 scope 字段。
- 店铺和 SKU 不存在/不可见时不泄露其存在性。
- 取消状态不能被迟到的后台执行结果覆盖。
- 输出仅标注实际查询到的来源；不可把未运行任务显示为成功。
- 失败信息不包含密钥、客户联系方式或未脱敏模型输入。
