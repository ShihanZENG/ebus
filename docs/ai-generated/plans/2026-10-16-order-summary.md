# 首页全量订单汇总 Implementation Plan

**Goal:** 第四批先替换首页订单数量、状态和分币种金额，摆脱前100条限制；其余库存/采购当前页指标仍明确标记，不假称全部完成。
**Architecture:** GET /orders/summary 复用orders:read和店铺范围；SQL聚合全量订单及未取消金额，静态路由先于order_id；首页请求失败显示不可用而非假0。
**Tech Stack:** FastAPI/SQLAlchemy、React/Ant Design。
**Spec:** 已确认五批路线第四批；本切片不汇率转换、不把订单金额当回款；收款/退款净额汇总及异常工作台后续实现。
