# 前端（跨境电商 ERP 管理后台）

Vite + React 18 + TypeScript + Ant Design 5，视觉与交互参考领星（LingXing）跨境电商 ERP：
深色业务模块栏、可收起的模块菜单、顶部可关闭业务页签、面包屑、卡片式数据看板与业务表格。

点击模块栏切换菜单，点击菜单打开对应业务页签；首页页签固定，关闭当前页签后转到其他已打开页签。页签用于导航切换，尚未保留各页面未提交的表单或筛选状态。

## 启动

后端需先在 `127.0.0.1:18080` 运行（参见 [后端说明](../backend/README.md)），然后：

```bash
cd frontend
npm install
npm run dev        # http://127.0.0.1:15173
npm run typecheck  # 类型检查
npm run build      # 生产构建
```

`/api` 请求由 Vite 代理转发到后端，因此页面上登录与取数都是真实调用。
登录账号 `admin`，密码见 `backend/.env` 的 `ERP_ADMIN_PASSWORD`。
本地开发登录页提供“填入演示账号”按钮，会从 `backend/.env` 回填管理员凭据但不会自动登录；该凭据只注入 Vite 开发服务器，生产构建不包含。

## 目录结构

```
src/
├── api/          接口层：client.ts（fetch 封装 + 401 处理）、auth.ts、lookups.ts（id→名称映射）
├── auth/         AuthProvider：登录态、/auth/me 校验、失效自动登出
├── components/   ResourcePage：配置驱动的通用资源页（搜索/分页/新增/编辑）
├── config/menu.ts 分组导航、页面权限与面包屑配置
├── layouts/      MainLayout：业务模块栏 + 模块菜单 + 可关闭页签 + 面包屑
└── pages/        业务页面
```

## 已接入的菜单与页面

以下页面均已接入后端接口；接口路径统一以 `/api/v1` 为前缀。商品与 SKU、采购单与补货建议分别复用带标签页的页面组件；采购计划、采购变更和供应商报价使用独立页面与记录。

| 分组 | 页面 | 后端模块 | 主要接口 |
|---|---|---|---|
| 首页 | 数据看板 | 聚合 | `/orders` `/inventory` `/purchase-orders` `/replenishment-suggestions` |
| 商品中心 | 商品、SKU、Listing 映射 | ERP | `/products` `/skus` `/listings` |
| 销售 | 销售订单、售后、客服工单 | OMS | `/orders` `/orders/{id}/after-sales` `/customer-tickets` |
| 仓储 | 库存余额、入库单、出库单、库存流水、FBA 发货计划 | WMS | `/inventory` `/inbound-orders` `/shipments` `/inventory/transactions` `/fba-plans` |
| 采购 | 采购计划、补货建议、采购单、采购变更、审批工作台、收货单、供应商、供应商报价、当前供货价 | SCM | `/purchase-plans` `/replenishment-suggestions` `/purchase-orders` `/purchase-amendments` `/supplier-quotes` `/supply-infos` |
| 基础资料 | 店铺、仓库档案、币种与单位 | ERP | `/shops` `/warehouses` `/dictionaries` |
| 系统 | 账号与角色、操作日志 | 权限 | `/users` `/roles` `/permissions` `/audit-logs` |

当前主要操作：

- 商品支持查询、新增和编辑；SKU 支持查询、新增、编辑规格属性和启停。已有 SKU 编码及所属商品不可修改，当前未提供删除 SKU 的入口。
- 销售订单支持手工建单、多行商品明细、详情、选择仓库后审核、发货申请与取消；售后支持查询并标记完成或驳回。
- 仓储支持库存查询、手工入库、入库单创建、出库确认、库存流水查询，以及按仓库和 SKU 盘点调整。盘点填写实际在库数量与原因，界面显示差异，目标数量不能低于已预留库存。
- 采购计划支持多 SKU 草稿、提交、审批、驳回和转采购草稿；补货建议支持计算、调整数量与原因、转采购草稿。
- 采购单支持新建、编辑草稿明细、提交审批、通过/驳回、取消和收货；已审批采购单通过采购变更申请改数量、单价、到货日与备注，变更记录保存审批意见和前后快照。收货后不允许此类变更。
- 审批工作台独立列出待审批采购单；收货单页面支持合格与不合格数量登记及收货记录查看。合格数量增加库存。
- 供应商报价逐条保留历史；接受报价会更新当前供货价与交期。当前供货价可单独查看和维护。
- FBA 发货计划支持草稿、审批、国内仓发货和海外仓全量签收；Listing 映射支持店铺与 SKU 的本地关联；客服工单支持分派、处理记录及状态流转。
- 店铺、仓库档案、供应商、币种与单位支持查询、新增与编辑。
- 账号与角色支持创建账号、启停账号、分配角色、重置密码、创建和编辑角色权限，以及查看账号详情；创建账号时可指定店铺和仓库数据范围。
- 操作日志支持列表、资源筛选和分页查询。

## 登录与权限

- 登录后通过 `/auth/me` 获取角色和权限；刷新页面时重新校验会话，收到 `401` 后清除登录态。
- 菜单按读取权限显示，空分组自动隐藏；直接访问无权限的业务路由会返回首页。
- “账号与角色”仅管理员可见、可进入；其他页面按 `config/menu.ts` 中的权限映射控制访问。
- 首页按当前账号权限请求数据；前端入口控制配合后端接口鉴权，具体操作权限与数据范围由后端校验。
- 商品、SKU、订单、采购、库存等写操作依据对应写权限显示或禁用；只读账号可查看其授权范围内的页面。

## 说明

- **看板使用接口数据**：订单状态分布、库存预警、待办数量由前端汇总接口返回记录。当前每类最多读取首页 100 条，属于当前加载数据的概览，不代表全量经营统计；无权限的模块不取数。
- **看板金额按币种分组**：销售金额按订单原币分别统计，不做汇率折算。
- **库存变动遵循中国习惯配色**：增加显红、减少显绿（见库存流水页）。
- **通用资源页**：店铺/仓库/供应商/字典/供货信息共用 `ResourcePage`，字段以配置声明，编辑时自动剔除后端 `extra=forbid` 禁止提交的不可变字段（如 `code`）。
- **采购收货边界**：全部合格收齐后采购单自动关闭；不合格收货仅记录，后续退换、补收及差异关闭流程尚未接入。

## 演示数据

演示数据由 `backend/scripts/seed_demo.py` 通过业务接口写入，包含商品、SKU、店铺、仓库、订单、采购及库存相关数据。后端启动后可在项目根目录执行，具体配置见后端说明：

```powershell
cd backend
.venv/Scripts/python.exe scripts/seed_demo.py
```
