# 织间 ZHIJIAN STUDIO｜独立站高保真视觉改版说明

版本：2026-10-21 · 基于用户上传的 `storefront.zip` 进行**增量 UI 改造**，不是替换为无功能模板。

## 设计方向
- 以「现代女装品牌 / editorial commerce」为方向，使用克制的奶油白、砂岩米、可可棕、深墨黑配色，以及中文衬线标题 + 英文字距体系。
- 导航：左侧浏览 / 中央品牌 / 右侧账户与购物袋，移动端重新排列。
- 首屏：大幅秋日穿搭图 + 品牌标题 + 单一核心行动按钮。
- 商品列表：4/3/2 列响应式陈列、产品类别、价格、视觉标签、鼠标悬停操作。
- 详情：双列大图 + 商品信息 + 规格选择 + 可折叠材质和尺寸信息。
- 结账：不改动购物袋、原提交恢复、订单访问凭证与 API 调用的关键逻辑；升级视觉排版。
- 品牌故事/底部：更清晰的故事视觉与帮助导航。

## 如何查看

### A. 立即看视觉样稿（不需要安装）
直接双击 `design-preview.html`。所有引用的本地图片和 CSS 都在同一解压目录下。该文件不连接服务器，无法真实结账。

### B. 运行真实 React 开发环境

```bash
npm ci
npm run dev
```

打开终端显示的本地 Vite 地址。**真实工作模式**仍然请求 `/api/storefront/v1`，需要照旧启动项目的 ERP 后端或代理。

### C. 没有启动 ERP 后端但想看 React 前端

访问 `http://127.0.0.1:15174/?preview=1`。

- React 页面加载明确标注的模拟概念产品。
- 仍可进行产品查看、规格选择、加入购物袋的纯前端演示。
- 视觉预览不会把模拟商品提交到 ERP，结账按钮被禁用。
- 移除 `?preview=1` 并连接原 ERP 后端，即恢复原有 API 商品数据模式。

## 功能边界与测试
- 完整保留原 `/api/storefront/v1` API 契约；本次没有修改后端。
- 原订单创建幂等与原提交恢复逻辑、查询凭据、客服工单及隐私分析开关均保留。
- **已运行：** TypeScript `tsc --noEmit` 通过；原 `node --test tests/*.test.mjs` 12/12 通过。
- **本环境未完成：** Vite 构建（原压缩包中仅含 Windows 原生依赖，当前 Linux 环境无法离线安装平台依赖）；真实浏览器视觉回归（受沙盒浏览器访问限制）。正式发布前请在本机 `npm ci && npm run build`，然后测试桌面和手机端。
- `look-01.jpg` 等由原概念图裁切，**不能替代真实商品摄影**。上架需使用真实 SKU 图、核实成分与尺寸信息。

## 改进后仍建议优先做的工作
1. 为实际商品拍摄或生成已核验的独立商品摄影素材（同一裁切比例）；概念图不应冒充商品实拍。
2. 在真实后端联调环境回归购物袋、变价、缺货、订单创建、重试和售后附件上传。
3. 再根据目标客户做真实站点名称、公司主体、英国市场消费者政策、支付与物流接入。
