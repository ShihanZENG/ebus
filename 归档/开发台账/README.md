## 开发与交付顺序

1. 完成 ERP 需求设计和基础资料功能，形成共用数据与接口。
2. 开发 OMS 建单、导入、审核及发货申请，接口先按约定准备。
3. 开发 WMS 手工入库、预留、出库，联调 OMS，完成订单发货流程。
4. 开发 SCM 采购与补货，补齐 WMS 采购收货及回执联调。
5. 完成四系统端到端验收、部署和使用说明。

跨系统依赖表示对应接口或功能需要就绪，不要求等整个系统交付后才开始下一系统。WMS 的采购收货验收安排在 SCM 对接阶段。
