# 广告：推广投放

## 页面用途

广告模块查看各渠道广告活动的投放效果，包括花费、销售额、ACOS 和 ROAS。路由为 `/ad-campaigns`。前端实现见 [`AdCampaignsPage.tsx`](../../../frontend/src/pages/AdCampaignsPage.tsx)。

## 数据来源

广告数据来自外部 DataLab 数据仓库，通过后端代理接口 `GET /api/v1/datalab/table/dws_ads_campaign` 拉取。这是只读数据，不能在本系统中创建或修改广告活动。

## 页面内容

| 卡片 | 说明 |
|---|---|
| 广告活动数 | 总活动数量 |
| 总花费 | 所有活动花费合计 |
| 总销售额 | 所有活动带来的销售额合计 |
| 平均 ROAS | 销售额 / 花费 |

表格列：活动名称、SKU、店铺、状态、花费、销售额、ACOS（进度条可视化）、ROAS。

## 权限说明

- `dashboard:read`：查看广告数据。
