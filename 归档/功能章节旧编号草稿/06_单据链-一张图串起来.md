# 单据链：一张图串起来

## 页面用途

前面各章节分别介绍了商品、销售、仓库、采购。本篇把这些模块串起来，说明一张订单从下单到完成，会触发哪些单据和库存变动。

## 完整单据流

```
[采购侧]
供应商报价 → 补货建议 → 采购计划 → 采购单 → 审批 → 收货入库 → 库存增加
                          │
                          └─→ 采购变更（数量/价格调整）

[销售侧]
平台订单 → 销售订单（draft）→ 审核 → 申请发货 → 出库单确认 → 库存减少 → 订单完成
                                              │
                                              └─→ 售后（退货/退款）

[FBA侧]
FBA 发货计划 → 审批 → 发货 → 收货 → Amazon 仓库存增加
```

## 库存变动追踪

每一步操作都会在库存流水中留下记录：

| 业务动作 | 库存影响 | 流水类型 |
|---|---|---|
| 采购收货 | on_hand +数量 | 入库 |
| 销售申请发货 | reserved +数量 | 预留 |
| 销售确认出库 | on_hand -数量, reserved -数量 | 出库 |
| 取消已预留订单 | reserved -数量 | 释放 |
| 手工库存调整 | on_hand ±数量 | 调整 |
| 其他入库 | on_hand +数量 | 入库 |

## 关联关系

- **Product → SKU**：一对多，一个产品有多个规格 SKU。
- **SKU → Listing**：一对多，一个 SKU 在不同店铺有不同 Listing。
- **Shop → Order**：一对多，一个店铺有多笔订单。
- **Order → OrderItem**：一对多，一笔订单有多行 SKU。
- **Supplier → PurchaseOrder**：一对多，一个供应商有多张采购单。
- **PurchaseOrder → Receipt**：一对多，一张采购单可分次收货。
- **SKU × Warehouse → InventoryBalance**：唯一一条余额记录。

## 当前实现边界

### 已实现

- 销售订单全链路状态流转与库存联动。
- 采购单全链路状态流转与收货入库联动。
- 库存流水完整记录每笔变动。
- 补货建议转采购单。

### 部分实现

- FBA 发货计划已实现，但与本地库存和 Amazon FBA 库存未联动。
- 采购变更单已实现，但与采购单的关联逻辑较简单。
- 售后记录已创建，但退货入库流程尚未完整闭环。

### 尚未实现

- 跨模块的单据关联视图（如从一笔订单反查其采购来源、从采购单反查其销售去向）。
- 单据打印模板。
- 全局操作日志跨模块查询（操作日志在设置模块单独记录）。
