# 采购：怎么买货回来

## 页面用途

采购模块（SCM）解决"库存不够了，怎么向供应商下单补货"的问题。完整链路是：**补货建议 → 采购计划 → 采购单 → 审批 → 收货入库**。路由分布在"采购"分组下：`/replenishment`（补货建议）、`/purchase-plans`（采购计划）、`/purchase-orders`（采购单）、`/purchase-approvals`（审批工作台）、`/receiving`（收货单）、`/suppliers`（供应商）、`/purchase-supplier-quotation`（供应商报价）、`/supply-infos`（当前供货价）。后端见 [`scm.py`](../../../backend/app/scm.py)。

## 采购状态机

```
补货建议（pending → converted/ignored）
  │
  └─ 转采购单（draft）
        │
        ├─ 提交审批 → submitted
        │     │
        │     ├─ 审批通过 → approved → 收货 → closed
        │     └─ 审批驳回 → rejected（可修改后重新提交）
        │
        ├─ 取消 → cancelled
        └─ 关闭 → closed（无收货）
```

## 各页面说明

### 补货建议（/replenishment）

系统根据销售速度和当前库存自动计算每个 SKU 应该补多少。
- 点击"计算补货建议"触发后端重算，基于最近销售周期和安全库存。
- 建议列表显示 SKU、当前库存、建议补货量、状态。
- 操作：将建议"转采购单"直接创建 draft 采购单，或"忽略"。

### 采购单（/purchase-orders）

| 字段 | 说明 |
|---|---|
| 采购单号 | 系统生成 |
| 供应商 | 选择已建档供应商 |
| 仓库 | 收货仓库 |
| 状态 | draft/submitted/approved/rejected/cancelled/closed |
| 明细 | SKU、数量、单价、金额 |

操作：新建采购单、提交审批、审批通过、驳回、取消、关闭。

### 审批工作台（/purchase-approvals）

只显示 `submitted` 状态的采购单，供审批人批量审批或逐条驳回。

### 收货单（/receiving）

在已审批的采购单上登记收货：选择 SKU、实收数量、批次备注。确认收货后自动增加该仓库的库存（联动 WMS）。

### 供应商（/suppliers）

CRUD：供应商编码、名称、联系人、电话、地址、状态。

### 供应商报价（/purchase-supplier-quotation）

记录某供应商对某 SKU 的报价：单价、报价日期、有效期。

### 当前供货价（/supply-infos）

展示 SKU 当前有效的供货价（从供应商报价中取最新一条有效报价）。

## 操作示例

1. 进入"采购 → 补货建议"，点击"计算"，系统生成各 SKU 补货建议。
2. 对某条建议点击"转采购单"，自动创建 draft 采购单。
3. 进入"采购单"，选择供应商和收货仓库，确认明细数量，提交审批。
4. 进入"审批工作台"，审批通过该采购单。
5. 供应商到货后，在"收货单"页面登记实收数量，确认后库存自动增加。

## 权限说明

- `purchase_orders:read/write`：采购单查看和创建/修改。
- `replenishment:read`：补货建议查看。
- `suppliers:read/write`：供应商管理。
- `supplier_quotes:read/write`：报价管理。
- `supplier_skus:read`：供货价查看。
- 审批操作要求 `purchase_orders:write`。

## 当前实现边界

### 已实现

- 完整采购单状态流转：draft → submitted → approved → closed。
- 补货建议自动计算和转采购单。
- 收货登记并联动 WMS 增加库存。
- 供应商档案、报价、供货价管理。
- 审批工作台。

### 部分实现

- 补货计算基于简化的销售速度模型，没有考虑在途库存、安全库存天数等参数配置。
- 收货登记后直接增加库存，没有质检流程。
- 采购计划页面已创建，但计划与采购单的联动较简单。

### 尚未实现

- 采购退货单。
- 供应商对账单、采购发票匹配。
- 多供应商比价自动推荐。
- 采购预算控制。
- 到货预告、预约收货。
- 采购变更单（已有 `/purchase-amendments` 路由和页面，支持变更数量/价格）。

## 验收步骤

1. 进入补货建议页，点击计算，确认生成建议。
2. 转一张采购单，提交审批，在审批工作台审批通过。
3. 在收货单页登记收货，确认库存增加。
4. 在供应商页新增一个供应商，在报价页为该供应商添加 SKU 报价。
5. 在供货价页确认报价生效。
