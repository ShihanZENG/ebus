# 统计：报表分析

## 页面用途

统计模块按店铺和日期查看销售趋势和汇总指标。路由为 `/statistics`。前端实现见 [`StatisticsPage.tsx`](../../../frontend/src/pages/StatisticsPage.tsx)。

## 数据来源

销售数据来自外部 DataLab 的 `dws_sales_store_day` 表（3652 条记录），通过 `GET /api/v1/datalab/table/dws_sales_store_day` 拉取。

## 页面内容

| 卡片 | 说明 |
|---|---|
| 总订单数 | 所选时间范围内订单总数 |
| 总销售额 | 订单金额合计 |
| 退款金额 | 退款合计 |
| 净销售额 | 销售额 - 退款 |

表格列：日期、店铺、平台、订单数、订单金额、已付金额、退款。支持按店铺下拉筛选。

## 操作示例

1. 进入"统计 → 经营统计"。
2. 在右上角下拉选择某个店铺，查看该店铺的销售明细。
3. 查看顶部汇总卡片了解整体销售情况。
