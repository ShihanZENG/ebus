# 设置：系统配置

## 页面用途

设置模块管理店铺、账号和操作日志。路由为 `/shops`（店铺资料）、`/users`（账号与角色）、`/audit-logs`（操作日志）。前端实现见 [`ShopsPage.tsx`](../../../frontend/src/pages/ShopsPage.tsx)、[`UsersPage.tsx`](../../../frontend/src/pages/UsersPage.tsx)、[`AuditLogsPage.tsx`](../../../frontend/src/pages/AuditLogsPage.tsx)。

## 页面内容

### 店铺资料（/shops）

| 字段 | 说明 |
|---|---|
| 店铺编码 | 唯一 |
| 店铺名称 | |
| 平台渠道 | Amazon / Shopify / TikTok 等 |
| 币种 | 默认结算币种 |
| 状态 | 启用/停用 |

### 账号与角色（/users）

| 字段 | 说明 |
|---|---|
| 用户名 | 登录账号 |
| 姓名 | 显示名 |
| 角色 | admin / operator |
| 权限列表 | 该用户拥有的功能权限 |
| 状态 | 启用/停用 |

管理员可重置密码、分配权限、设置数据范围（店铺范围、仓库范围）。

### 操作日志（/audit-logs）

只读列表，记录谁在什么时间对什么数据做了什么操作。

## 数据来源

| 操作 | 接口 |
|---|---|
| 店铺 CRUD | `/api/v1/shops` |
| 用户 CRUD | `/api/v1/users` |
| 操作日志 | `/api/v1/audit-logs` |

## 权限说明

- `shops:read/write`：店铺管理。
- `users` 页面仅管理员可见。
- `audit:read`：查看操作日志。

## 当前实现边界

### 已实现

- 店铺档案 CRUD。
- 用户管理（管理员）。
- 操作日志记录和查询。

### 尚未实现

- 角色管理（自定义角色和权限模板）。
- 登录策略（密码复杂度、过期策略）。
- 双因素认证。
- 店铺 API 凭证管理（Amazon MWS/LWA 凭证加密存储）。
- 系统参数配置页。
