# 客服：售后消息

## 页面用途

客服模块处理客户咨询和售后问题。路由为 `/customer-tickets`（客服工单）和 `/after-sales`（售后）。前端实现见 [`CustomerTicketsPage.tsx`](../../../frontend/src/pages/CustomerTicketsPage.tsx) 和 [`AfterSalesPage.tsx`](../../../frontend/src/pages/AfterSalesPage.tsx)。

## 页面内容

### 客服工单（/customer-tickets）

| 字段 | 说明 |
|---|---|
| 工单编号 | 系统生成 |
| 标题 | 问题摘要 |
| 客户 | 咨询客户 |
| 状态 | open / resolved / closed |
| 优先级 | low / medium / high |
| 创建时间 | |

操作：创建工单、更新状态、添加回复。

### 售后（/after-sales）

售后记录关联销售订单，记录退货/退款申请。
- 售后类型：退货、退款、换货。
- 状态：pending / approved / rejected / completed。

## 数据来源

| 操作 | 接口 |
|---|---|
| 工单列表 | `GET /api/v1/customer-tickets` |
| 售后记录 | `GET /api/v1/orders/{id}/after-sales` |
| 创建售后 | `POST /api/v1/orders/{id}/after-sales` |

## 权限说明

- `customer_tickets:read`：查看工单。
- `after_sales:read/write`：查看和创建售后记录。

## 当前实现边界

### 已实现
